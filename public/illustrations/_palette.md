# Illustrations

These are in-house stand-ins drawn in unDraw's flat style, with the AgriScan
accent `#16C172` already baked in, so the app ships complete.

To swap in the real thing: go to https://undraw.co/illustrations, **set the
colour picker to `#16C172` first**, download the SVG, and overwrite the file
here keeping the same filename. Nothing else needs to change.

| File | unDraw search term |
|---|---|
| `hero-farm.svg` | "farm girl" / "gardening" |
| `secure-login.svg` | "secure login" |
| `welcome.svg` | "welcome" |
| `forgot-password.svg` | "forgot password" |
| `scan-leaf.svg` | "camera" / "photograph" |
| `analysis.svg` | "data processing" / "science" |
| `diagnosis.svg` | "medicine" / "doctors" |
| `growth.svg` | "growth analytics" |
| `eco-farming.svg` | "eco conscious" / "environment" |
| `no-data.svg` | "no data" |
| `empty-state.svg` | "empty" |
| `not-found.svg` | "void" / "page not found" |

Filenames must stay under `/illustrations/` — the dark-mode brightness rule in
`app/globals.css` keys off that path.

Palette: brand `#16C172`, deep `#0B7F4B`, mint `#D2F9E2`, pale `#ECFDF4`,
line `#CBD9D1`, ink `#04291C`.
